What it does វាធ្វើអ្វី

Helps you plan a small or medium app before you code: decide what goes in the first version (the MVP), split the code into UI, service and data layers, draw how data moves, and write down each design choice and why.

When to use it ពេលណាគួរប្រើ

Type something like this to your AI tool, or call it by name with /system-design.

  • Plan the MVP for a library book-borrowing app.
  • How should I structure the folders for this project?
  • Draw the data flow for user sign up.
  • My app works but the code is a mess. How do I split it?

What it needs ត្រូវការអ្វីខ្លះ

  • Nothing extra. Only your AI tool.

Install just this skill ដំឡើងតែ skill នេះ

Your computer កុំព្យូទ័ររបស់អ្នក

Paste in PowerShell:

& ([scriptblock]::Create((irm https://daraboth.github.io/skilljmskill/install.ps1))) --skills system-design

Paste in Terminal:

curl -fsSL https://daraboth.github.io/skilljmskill/install.sh | sh -s -- --skills system-design

The menu still asks which AI tool and where. Needs Node.js 18 or newer.
