# Product

<!-- impeccable:product-schema 1 -->

Inferred from the repository and the owner's written brief; no interview round was possible.
Every fact below is marked (inferred) where it was not stated by the owner.

## Platform

web

## Stack

Static HTML and CSS with a little vanilla JavaScript, generated by `tools/build_site.py` from
`skills/*/SKILL.md` and served by GitHub Pages from the `main` branch root. No build tools, no
frameworks, no external JS libraries. Google Fonts allowed. (owner brief)

## Users

Cambodian IT students and junior developers who use AI coding tools (Claude Code, Codex, Gemini
CLI, GitHub Copilot, Cursor, OpenCode). Many read English as a second language and are more at home
in Khmer. They often open the site on a phone, from a link shared in a class or chat group, then
install on a laptop later. (owner brief, README)

## Product Purpose

A free pack of skills (one folder each, with a SKILL.md) that teach an AI coding tool to do one job
well. The site lets a student understand what each skill does, decide which ones they want, and
install them: one command that opens a chooser, a command for a chosen set, or a zip of one skill to
unzip by hand. Success: a student finds the right skill in seconds and installs it without help.

## Positioning

Made for Cambodian students: bilingual English and Khmer, plain short words, nothing installed until
the student chooses, works for six AI tools, not only one. (README)

## Operating Context

Students copy a command into PowerShell (Windows) or Terminal (Mac/Linux). The installer needs
Node.js 18+. Skills land in a tool-specific folder, per project or per user (table in README).

## Capabilities and Constraints

- Install everything through a chooser: `irm .../install.ps1 | iex` or `curl ... | sh`.
- Install chosen skills: `--skills a,b` passed through the installer.
- Some skills have extra needs (Node, git, Windows only, an Orbit account, Orca terminal).
- Third-party skills keep their own licence in their folder.
- No personal paths, emails or company names on the site. (owner brief)

## Brand Commitments

Name: SkillJM Skill. Khmer labels next to English headings. No em dashes, no emoji. (owner brief)

## Evidence on Hand

The 44 skill folders and their SKILL.md files, the README. No testimonials, user counts or download
numbers exist; do not invent any.

## Product Principles

1. The student chooses: nothing happens without their say.
2. Plain words first; Khmer beside English, never hidden.
3. Every skill explains itself before asking to be installed.
4. One working command beats a long explanation.

## Accessibility & Inclusion

Phone first (iPhone), keyboard usable, visible focus, real contrast in light and dark, reduced motion
respected, Khmer script rendered with a Khmer-capable font at a comfortable size. (owner brief)
